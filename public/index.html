首次使用
  1. 打开并登录 Discord 桌面客户端。
  2. 创建 Discord 应用，填入 Application ID。
  3. 确认 Discord 的活动隐私设置允许分享活动。
  4. 编辑内容，点击「启用 Presence」。

服务无需 Bot Token 或用户 Token。Streaming、名称覆盖、链接及高级字段的支持取决于客户端，可能被忽略。

Custom Status / Emoji、created_at、flags 等不是本工具可写入的 RPC 显示字段。邀请封面用于游戏邀请，个人资料卡不会显示。
